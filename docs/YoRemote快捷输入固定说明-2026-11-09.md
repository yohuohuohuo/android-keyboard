# YoRemote 0.1.5：固定模式说明

修复快捷输入辅助模式下，说明文案随着每次发送切换、右侧停止按钮反复出现和消失的问题。模式说明现在只随当前模式变化，不随发送状态轮换。

- 普通模式固定显示“普通发送不附加回车；候选显示在 Mac。”。
- 边输入边发固定显示“输入后自动发送；候选显示在 Mac。”，自动发送不显示逐次发送中/成功状态和停止按钮。
- 手动点击发送或使用输入法发送，仍显示独立的状态行和停止按钮，长文本可中途停止；状态行放在模式说明下方，不挤占说明宽度。
- 失败、不支持字符、取消提示仍显示，保留草稿及必要的原提交快照；取消和报告释放沿用原逻辑，不增加重试或缓存队列。

`VirtualKeyboard.kt` 用一个可恢复的提交来源标记区分自动与手动提交。辅助模式因忙时编辑退出后，原自动任务不会被误认成手动任务。`yoremote.xml` 增加辅助模式的固定说明；发送任务、节奏、字符映射和蓝牙逻辑均未改。`ControlPagesTest.kt` 增加三项回归并扩展忙时编辑回归。构建版本同步为 0.1.5 / versionCode 13。
