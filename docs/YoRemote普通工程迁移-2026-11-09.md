# YoRemote 普通 Android 工程迁移

用户不再需要跟随或合并上游，2026-11-09 将 YoRemote 转为根仓库直接管理源码的普通 Android 工程。当前开发流程以根目录 README、AGENTS.md 和本记录为准；其他历史记录中的 src 子模块、补丁和重放命令只解释当时的产物，不再作为操作步骤。

## 现在如何开发

1. Android Studio 打开仓库根目录。
2. 直接修改 `app/src/main/` 的 Kotlin、Manifest 与资源，相关测试也直接修改 `app/src/test/`、`app/src/androidTest/`。
3. 版本号与构建类型只在 `app/build.gradle.kts` 维护；依赖版本在 `gradle/libs.versions.toml`。
4. 从根目录运行 `./gradlew testDefaultDebugUnitTest assembleDefaultOptimized`，按改动范围补充 lint、instrumentation 与真机回归。
5. 用 `git status`、`git diff` 和 `git diff --cached` 检查源码与暂存内容，正常提交、推送。不需要补丁、子模块提交或手工重放。

优化包默认输出为 `app/build/outputs/apk/default/optimized/app-default-optimized.apk`。保留重要构建时另存到忽略的 `artifacts/`，不要覆盖旧 APK。覆盖安装仍需原 Debug 密钥；密钥被忽略，不会随 Git clone 分发。
