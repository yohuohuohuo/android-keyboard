# YoRemote 0.1.3：竖屏方向键十字布局

按用户最后补充的十字示意图实施：竖屏将四个方向键从键盘矩阵移到下方留白处，上、下、左、右各居一边，中心留空；普通层空格键占据移走方向键后腾出的宽度。横屏布局保持不变。

## 实现

- 主矩阵仍为 320dp，普通层和功能层的方向键都迁出，每个方向只保留一个按钮。
- 方向键为 52dp 方形触控区，图标按按钮一半尺寸显示；十字整体为 172dp，中心无按钮、点击不发送报告。沿用现有主题和 IconSurfaceButton。
- 正常竖屏保持主矩阵居中，十字居中放入其下方留白。较矮窗口不足以同时容纳时，矩阵与十字组合居中；放不下时可滚动到底部，四 Tab 始终在外层。
- 普通层 Ctrl / Option / Cmd 保持原权重，四个移出方向键的权重转给空格键，因此空格键填至最右边。
- 方向键和矩阵共用 KeyboardReportState，保留 Cmd/Shift 等修饰状态，按下/释放继续使用原键盘报告，不使用消费控制报告，不新增中心确认动作或自动发送。

产品修改位于 `AdvancedKeyboard.kt`；原布局数据及横屏分支保持。补充 `ControlPagesTest.kt` 几何、中心空白、Cmd+左方向键和小窗口可达性回归。构建版本为 0.1.3 / versionCode 11。
