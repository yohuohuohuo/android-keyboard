# YoRemote 0.1.2：竖屏键盘定高居中

用户要求：竖屏键盘不强行铺满上下空间，使用合适的固定高度，在屏幕上下居中。按当前项目原生 Compose 键盘组件修改，保留原按键排列、发送与释放行为。

## 布局决定

- 竖屏普通层和功能层使用 **320dp** 固定高度，在设备顶栏与底部 Tab 之间的可用内容区垂直居中。
- 320dp 是按现有五行布局选取的实现尺寸，每行约 61dp；没有把用户截图的 1080×2400 像素直接换算成 dp。截图的设备密度和字体缩放未知。
- 横屏沿用原有父约束高度与紧凑排列；窗口不足时保留滚动，不裁掉无法触达的按键。
- 不增加高度设置项，不改按键映射、文字发送节奏、连接或草稿规则。

产品代码仅调整 `AdvancedKeyboard.kt` 的方向判断、竖屏高度与父容器居中；`ControlPagesTest.kt` 检查实际组件几何边界与可达性。构建脚本和转换索引基线的版本同步为 `0.1.2` / `10`，追加补丁重新导出。

## 验证与证据

- 先在旧实现添加回归，实际竖屏矩阵高度为 **680dp**，与预期 320dp 不符，测试失败。失败日志及 XML 保存在 `artifacts/yoremote-portrait-evidence/portrait-red.log`、`portrait-red-results/`。
- 修改后 360×800dp 的矩阵高 320dp，矩阵中心与内容区中心一致；800×360dp 横屏仍占原可用高度。
- 360×360dp 的紧凑竖屏可滚动到 Cmd 等底行按键，四 Tab 仍可达。
- 已检查生成的原生模拟截图，普通竖屏矩阵上、下留白相等。截图使用测试主题，颜色可能与手机动态配色不同；没有重绘或 AI 生成示意图。
