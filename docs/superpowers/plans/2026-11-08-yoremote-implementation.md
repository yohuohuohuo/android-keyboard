# YoRemote 实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在当前项目内实施；最后进行一次独立代码复核。用户已批准实施，无需再次整体确认。

**Goal:** 交付四个独立控制页、可靠的事件报告和带反馈的英文/拼音发送，以及可共存安装的 YoRemote Debug APK。

**Architecture:** 四页共享 RemoteViewModel 和原 HID 服务。矩阵事件直接生成报告；文本复用原字符映射和 25ms 按下/释放节奏。子模块 HEAD 保持固定上游，定制通过追加补丁和独立目录重放，构建脚本不重置开发源码。

**Tech Stack:** Kotlin / Compose / AGP 9.2.1 / Gradle 9.5.0 / JDK 21 / Android SDK 36；JUnit 与 Robolectric Compose 本地 UI 测试。

**Spec:** `docs/superpowers/specs/2026-11-08-control-tabs-macos-chinese-design.md`

## Global Constraints

- 基础 applicationId `io.github.yohuohuohuo.btremote`，Debug 后缀 `.debug`，名称 `YoRemote`；namespace 保持 `com.atharok.btremote`。
- 不改鼠标手势/速度、文本 25ms 节奏；不加延迟重试、联网、汉字直传或后台重放。
- 不覆盖原 APK、签名、历史证据、已有 `.gitignore` 和 `.memsearch`。
- 不推送、不迁移数据、不修改根 gitlink，不对开发子模块执行 reset/clean 或重复 git am。
- 报告受理不等于 Mac 输入成功；手机/Mac 验证单独标记。

## Review Focus

- 同帧短按、连续同键、组合键及旧回调捕获；记录回调断言按下/释放数量与顺序。
- F7 与右 Option 字节相同但语义不同；显式修饰标记，按位组合。
- 文本失败、取消或发送中编辑时保留草稿；不自动重放、不隐式 Enter。
- 切页、功能层、旋转、后台和断线中止发送并释放三个报告族；清除本地按住状态。
- 360×800dp、800×360dp 与 IME 挤压下控制和 Tab 可达；离开键盘恢复先前方向策略。
