# android-bt-remote 安全审查与本地导入

审查日期：2026-11-08。该应用把 Android 手机作为蓝牙 HID 键盘、鼠标和媒体遥控器；本轮按个人手机控制一个已配对设备的场景审查。

## 结论

在本轮源码审查范围内，未发现阻止将其作为本地定制开发基础引入的恶意代码、输入外传或可直接利用的跨应用控制入口。已导入当前项目，保留原仓库历史、许可证、补丁和子模块结构。Debug 打包和现有示例单元测试通过，但 lint 未通过，不能视为已达到发布标准。

这项结论针对下面固定版本的源码，不代表对商店 APK、GitHub 预编译 APK 或蓝牙系统协议栈作出安全认证。

## 已检查的安全路径

- 审查根仓库的构建脚本、GitHub 发布工作流、三个补丁，以及子模块的 Gradle 配置、GitLab CI、清单、蓝牙连接/发送、权限、广播、前台服务、通知、小组件、设置存储和键盘输入路径；对其余源码进行敏感 API、外联及密钥模式检索。未逐行审查全部 UI、翻译和键盘布局映射。
- 主清单与合并依赖后的 Debug 清单均没有申请 `INTERNET`；应用源码未发现 HTTP 客户端、广告/统计 SDK、动态代码下载、shell 命令执行或输入内容日志。帮助/源码链接由用户操作后交给外部浏览器打开。
- HID 前台服务、通知控制接收器和小组件接收器不对其他应用导出；快捷设置服务使用系统绑定权限；通知 `PendingIntent` 指向明确组件并设置不可变标志。启动 Activity 不读取外部传入的控制指令。
- 蓝牙使用 Android 的 HID 与配对机制，发现可见性通过系统界面启用，申请时长为 300 秒。蓝牙连接安全仍依赖手机、目标设备的系统实现及用户确认的配对对象。
- 输入文本仅在输入界面状态中暂存，发送路径直接生成蓝牙 HID 报告。持久化内容主要为设备 MAC 地址、收藏和界面/遥控偏好，未发现保存输入历史。
- Gradle Wrapper JAR 的 SHA-256 与 Gradle 官方公布的 9.5.0 校验值一致：`497c8c2a7e5031f6aa847f88104aa80a93532ec32ee17bdb8d1d2f67a194a9c7`。校验源：<https://services.gradle.org/distributions/gradle-9.5.0-wrapper.jar.sha256>。

## 需要保留的安全边界

1. **输入框不是密码保护模式。** `VirtualKeyboard.kt` 使用普通文本框，未提供密码遮挡、禁止截图或输入法隐私模式。用户通过它输入密码时，普通输入模式可能让内容显示在手机屏幕上，所选输入法也会接触输入；不能将它当作专门的敏感凭证输入工具。若定制目标包含密码输入，应另行设计并验证该行为。
2. **系统备份包含设备元数据的可能性。** `allowBackup=true`，备份规则未排除 DataStore；设备地址、收藏和偏好设置可能进入系统备份或设备迁移。没有发现输入文本写入该存储。需要完全本地保存这些元数据时，应收紧备份规则。
3. **Kotlin 工具链存在已知公告，但当前未发现受影响路径启用。** 声明的 Compose 插件 2.4.0 会依赖同版本 Kotlin Gradle 插件；OSV 命中 `CVE-2026-53914 / GHSA-r937-wjx7-w2jp`。官方修复修改的是 KAPT 增量缓存反序列化，本项目没有启用 KAPT 或注解处理器，因此本轮未将其判定为当前可触发漏洞。后续启用 KAPT 或接入共享构建缓存前，应升级并重新核查工具链。参考：[公告](https://github.com/advisories/GHSA-r937-wjx7-w2jp)、[JetBrains 修复提交](https://github.com/JetBrains/kotlin/commit/bf51df665b458fda7c3eaf436c4d88dc119d7ec6)。

- OSV 对 16 个显式版本坐标（含构建插件）进行查询，除上述 Kotlin 公告外未命中其他记录；再对 `defaultDebugRuntimeClasspath` 解析得到的 210 个 Maven 坐标（包括传递依赖、BOM 和约束）进行查询，未命中漏洞记录。未穷举构建工具全部传递依赖；查询也不覆盖尚未披露的漏洞。
- `:app:assembleDefaultDebug` 完成，已生成 Debug APK；`:app:testDefaultDebugUnitTest` 完成，1 个示例测试通过，0 失败。该测试仅验证 `2 + 2 = 4`。
- `:app:lintDefaultDebug` 失败：234 个错误、37 个警告。错误分布为 227 项缺失翻译、6 项 Compose 资源读取方式问题、1 项 `MissingPermission`。已检查该权限告警对应的 `sendAndroidReport()` 全部调用：当前都有外层蓝牙权限检查，但 helper 本身缺少所需权限声明；未发现可据此绕过系统权限的调用路径，权限撤销时序尚未做真机验证。这些问题保留为后续开发/发布前的质量事项，本轮没有修改源码或降低 lint 标准。
