# 手机连接 Mac 测试包

## 安装包

- 文件：`artifacts/android-keyboard-0.0.7-debug.apk`，约 71 MiB。
- 手机显示名称：Bluetooth Remote。
- 版本：`0.0.7-debug`，包名：`io.github.jqssun.btremote.debug`。
- 最低 Android 版本：9（API 28）；手机系统需支持 Bluetooth HID Device。
- 通用 APK：包含 arm64-v8a、armeabi-v7a、x86、x86_64，无需选择分包。
- SHA-256 记录在 `artifacts/SHA256SUMS`。

本包来自 2026-11-08 的本地审查构建：根仓库 `035a3afa420fa7c40bbe5b337752fa76a276ea7e`、子模块 `56ea84e6b8f16e45c6467768b72e1bcd8f322f72`，已应用原仓库三个补丁及 `build.sh` 的资源、包名和版本替换。未加入定制功能。

## 安装与配对

1. 将 APK 传到 Android 手机上，打开安装；系统要求时，为当前文件来源开启“允许安装未知应用”。
2. 打开 Bluetooth Remote，开启蓝牙并允许“附近的设备”权限；Android 9～11 扫描时可能需要位置权限。
3. 在应用的设备/配对引导中开启手机蓝牙可见性。Mac 打开“系统设置 → 蓝牙”，选择这台手机并在两端确认配对。
4. 在应用设备列表选择 Mac，确认应用显示已连接；Mac 不需要安装接收端程序。

## 基础检查

- **鼠标**：在手机的鼠标/触控板区域滑动，确认 Mac 指针移动；再测试左键、右键和滚动。
- **键盘**：Mac 打开一个空白文本编辑文档，先切换为英文输入；手机打开键盘输入框，输入 `abc123` 并点击发送，再测试空格、退格和回车。键盘布局可先选英语（美国）。
- 如需实时发送，可开启键盘输入框旁的 Direct Input（直接输入）开关；先按普通发送模式确认基础链路。
- 记录失败发生在“发现设备、配对、连接、指针、点击、滚动、文本发送”的哪一步，以及手机型号、Android 版本、Mac 型号和 macOS 版本，便于后续定位。

## 验证与限制

Debug 打包、现有 1 个示例单元测试、APK ZIP 完整性及 APK v2 签名验证通过；未做真机配对/输入验证。Android lint 仍为 234 个错误、37 个警告，详情见 [安全审查记录](安全审查与导入记录-2026-11-08.md)。此包用于当前连接测试，尚未达到发布标准。

手机输入法整段中文提交不属于当前已确认能力；普通输入框也没有密码保护，本轮先使用普通英文和数字测试。

测试签名保存在被 Git 忽略的 `artifacts/.android-home/debug.keystore`，后续 Debug 构建可复用该 `ANDROID_USER_HOME`，以保持签名一致。该签名仅用于测试。
